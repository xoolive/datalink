# Glossary

- `VDL2`: VHF Data Link Mode 2 bearer.
- `AVLC`: VDL2 link control framing (I/S/U frames).
- `ACARS`: message transport/envelope used across multiple bearers.
- `ARINC 622`: app envelope conventions layered over ACARS for ATS apps.
- `CPDLC`: controller-pilot data link communications application.
- `ADS-C`: surveillance-contract reporting application.
- `HFDL`: High Frequency Data Link bearer for long-range/oceanic coverage.
- `POA VHF ACARS`: classic VHF ACARS channels (e.g. 131.xxx MHz).
- `MIAM` / `OHMA` / `Media Advisory`: ACARS app families supported by libacars ecosystem.
- `CSC`: Common Signalling Channel for VDL2 (`136.975` MHz).
- `POA`: Plain Old ACARS (classic VHF ACARS bearer/modulation family).
- `OOOI`: Out/Off/On/In operational event reporting over ACARS flows.
- `ARINC` / `SITA`: major ACARS service-provider networks.
