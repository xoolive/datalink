## Changes observed in the retrieved file

Additions include station identifiers for John Wayne (KSNA), Huatulco (MMBT), Rotenburg (EDXQ), Eberswalde (EDAV), Oberpfaffenhofen (EDMO), Manchester (EGCC), Cork (EICK), Zielona Gora (EPZG), Brno (LKTB), Gyor (LHPR), Pecs (LHPP), Timisoara (LRTR), Nairobi (HKJK) and Goa Manohar (VOGA). Existing Timisoara frequency and Bogota coordinate descriptions are among the corrections.

The upstream `214A28` entry labels LKTB Brno Turany as Hungary. This appears geographically inconsistent; it is preserved verbatim rather than silently corrected. Station labels and observations remain community data, not independently verified ground truth.

This file is a reference dataset; Datalink does not automatically load it as a station lookup database.
